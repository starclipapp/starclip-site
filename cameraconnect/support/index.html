CameraConnect サポート

CameraConnectは、OI.Share（OM Image Share）のWi-Fi画像共有に対応し、同じOlympus互換HTTP APIを提供するOlympus／OM Systemカメラから、撮影済み写真と動画のプレビューをMacに表示・保存する独立したアプリです。対象は特定の2機種だけではありません。E-M5 Mark IIIとOM-1は実機検証中です。機種・ファームウェアによる応答差があるため、未検証機種の動作を保証するものではありません。OM SYSTEM／Olympusの公式アプリではありません。

カメラに接続する

  1. カメラの再生画面またはメニューから、Wi-Fiの画像共有接続を開始します。
  2. CameraConnectの「Wi-Fi設定を開く」、またはMacのシステム設定 > Wi-Fiを開きます。
  3. カメラ画面に表示されたSSIDへ接続し、カメラ画面のパスワードをmacOSに入力します。CameraConnectはWi-Fiパスワードを保存しません。
  4. CameraConnectが有効なカメラ応答を確認すると、自動的に「カメラと通信中」へ切り替わります。必要なら「写真一覧を更新」を押します。
  5. 使用後はmacOSのWi-Fi設定で普段のネットワークへ戻します。

カメラのWi-Fiに接続中は通常のインターネット接続が利用できない場合があります。Wi-Fiライブビュー、Bluetooth接続、遠隔シャッターには対応していません。

カメラなしで試す

ヘルプメニューの「デモを表示」を選びます。「デモ表示（カメラ未接続）」と表示され、同梱の合成サンプル画像を閲覧できます。デモ中はカメラへの通信と原寸ダウンロードを行いません。カメラとの通信を試す前に「デモを終了」を選んでください。

写真が表示されない

macOS 15以降では、ローカルネットワークへのアクセスを許可してください。許可しなかった場合は、システム設定 → プライバシーとセキュリティ → ローカルネットワークでCameraConnectをオンにします。

  • デモを終了し、Macがカメラ画面のSSIDに接続しているか確認します。
  • カメラのWi-Fi共有モードと、メモリーカードに写真があるか確認します。
  • カメラの共有接続を開始し直し、「写真一覧を更新」を押します。

接続中表示はSSID、キャッシュ、以前の接続情報ではなく、有効なOlympus／OM Systemカメラの応答から判断します。カメラの応答を失うと未接続へ戻ります。

原寸写真とプレビュー

「写真一覧を更新」はカメラ内の一覧、写真・動画のサムネイル、プレビューに含まれるEXIFの更新です。プレビューに含まれないEXIFは原寸保存後まで空欄になる場合があります。EXIFだけを目的に原寸を自動取得することはありません。

「全写真自動保存」はJPEGと設定で選んだRAWの原寸を保存します。動画は自動保存しません。進捗には保存済み件数／対象件数と保存中の写真名を表示します。「中止」で写真の原寸取り込みを止め、「再開」で未保存分を続けます。

「閲覧写真のみ保存」は写真を1秒間表示すると原寸保存を予約します。「全写真自動保存」と「手動保存」も選べます。手動では「この写真をMacに保存」を押します。

動画を再生する

動画は自動保存せず、最初はサムネイルだけを表示します。「ダウンロードして再生」を押すとMacの一時ファイルへ受信し、サイズを確認して保存してからローカルファイルを再生します。容量、進捗率、速度、残り時間を表示し、転送中の「中止」または待機中の「キューから削除」で1件だけ取り消せます。残りの動画キューは順番どおり続行します。中止した動画を再開する場合は先頭から取得します。

プレビューを見られるだけでは、原寸写真がMacに保存されたことにはなりません。保存状態を確認し、保存済み写真のFinder操作から実際の保存先を開いてください。保存先はmacOSのサンドボックスにより通常のホームフォルダ内の場所と異なる場合があります。

原寸保存に失敗したら、カメラの共有接続、空き容量、アプリに表示される保存先とエラーを確認してください。

キャッシュを削除する

設定の「プレビューキャッシュを削除」で一時プレビューを削除できます。上限は合計512MiB、保持期間は最終取得から7日です。アプリの処理時に削除します。保存済みの原寸写真は削除されません。自動取得が有効ならプレビューを再取得する場合があります。
